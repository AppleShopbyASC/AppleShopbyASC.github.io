# Mac 上手包・繁體中文使用說明

門市交給新購 Mac 顧客的繁體中文使用指南（W1 大封面版本）。

- **線上閱讀網址**：[https://appleshopbyasc.github.io/](https://appleshopbyasc.github.io/)
- **離線瀏覽方式**：下載後雙擊根目錄 `點我開啟 Mac 上手包.html`（或 `html/index.html`）即可離線開啟。

---

## 內容架構

1. **大封面入口（`index.html`）**：雜誌風格雙卡片選擇入口，單一路徑不迷航。
2. **第 1 冊：第一次用 Mac（`guide.html`）**：初次購買 Mac 之日常操作必備 12 章完整指南。
3. **第 2 冊：從 Windows 換過來（`windows.html`）**：
   - 常用操作 8 大技巧快捷膠囊入口
   - 16 件事並排速查表
   - 新機頭三天指南（含環境相容與安全換機）

---

## 設計與排版規範

- **全系統字型**：支援 Apple 系統字型與 Noto Sans TC，字級清楚好讀，零負字距。
- **純離線可用**：全站純靜態，無任何外部 HTTP/HTTPS 請求或 CDN 依賴，安全無隱私風險。
- **正向語意**：全繁體中文（台灣習慣與 macOS 官方用語），語氣溫暖正面。
